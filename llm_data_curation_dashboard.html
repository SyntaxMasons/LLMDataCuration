System Architecture Overview

The core infrastructure is orchestrated via a central API Gateway which routes all incoming client requests to the appropriate microservices. The microservices operate in an isolated VPC.

All read operations are cached heavily using a Redis cluster to reduce latency, while write operations are persisted directly to the primary PostgreSQL database cluster in a highly available configuration.

Figure 1.1: Request routing and data persistence flow.

Note: In the event of a Redis node failure, the application will fallback to direct database querying, potentially increasing response times by up to 300ms.
